# SQL Data Engineering Practice

This repo tracks my hands-on SQL practice while working through the **IBM Data Engineering Professional Certificate** (Coursera), plus extra interview-focused SQL work I'm doing alongside it.

## Why this repo exists

I wanted a public, organized record of SQL work that goes beyond "followed the tutorial" — each script includes the problem context, my approach, and notes on anything that tripped me up, so it doubles as a portfolio piece for data engineering roles.
